# Contact Book

A simple contact management app built with **React + Vite** as part of a school
individual activity. It displays user contacts on a responsive card grid and
includes a live search feature that filters contacts by name, email, or phone
as you type.

## Features

- Contact cards showing profile picture, name, email, and phone
- Responsive grid layout
- Live search/filter across name, email, and phone
- Empty-state message when no contacts match

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start the dev server     |
| `npm run build`| Build for production     |
| `npm run lint` | Run ESLint               |
| `npm run preview` | Preview the production build |
